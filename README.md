# OLD FASHIONED ("a la antigua")

El nombre proviene de que los estadounidenses que tomaban cocteles comenzacon a pedir el coctel "A LA ANTIGUA" es decir {licor + azucar + agua +  bitter}

- Enfriar un vaso de WHISKY
- Revolver 2 cucharadas de azucar (receta original 2 terrones de azucar) con 2 DASHES (chorros) de amargo de angostura. Se le puede agregar un poco de agua con gas o el destilado ocupado como base para su correcta integración
- Agregar hielo hasta colmar el vaso
- Agregar 2 oz de WHISKEY BOURBON [JIM BEAM] {podría ser un JACK DANIELS}
- Integrar removiendo bien
- Aromatizar con esencia de cáscara de toronja o naranja. Para una correcta extracción de los aceites esenciales separar el FLAVEDO (capa externa coloreada donde se encuentran los aceites esenciales) del ALVEDO (capa blanca de sabor amargo que contiene PECTINA)
- Decorar con media luna de naranja

# PUNCH (punch bowl)

Bebida pensada para compartir se elaboraba una ponchera (PUNCH BOWL) tendria un origen indio, que luego se popularizó en Europa

En un recipiente grande agregar las siguientes medidas de los siguientes ingredientes

- 1 (2 medidas): SOUR - cítricos, acidez (jugo de limón)
- 2 (4 medidas): SWEET - dulzor (jarabe de goma)
- 3 (6 medidas): STRONG - fuerza, destilado (MAYERS)
- 4 (8 medidas): WEAK - debilidad (té)
- 5 (10 medidas): SPICED - Especiado (Amargo de angostura)
- 6 ICE

Decorar con rodajas de limon y naranja con clavos de olor incrustados

# SOUR (ácido/agrio)

Bebida de estructura : DESTILADO + ACIDO + DULCE
La proporción varia de acuerdo al destilado o estilo, la formula moderno es : 60 ml destilado + 30 ml cítrico + 20 ml jarabe

- Enfriar un vaso de WHISKY
- Agregar hielo hasta cubrir el vaso
- Incorporar 2 oz de WHISKEY, 1 oz de jugo de limon Tahiti y 1 oz de jarabe de goma
- Integrar removiendo

La receta original indica
- 2 oz de WHISKEY (BOURBON)
- 3/4 oz de Jugo de Limón Tahiti
- 3/4 oz de jarabe de goma

# Tequila (México)

Denominación de origen (1997) : Franja tequilera (Jalisco + Guanajuato, Michoacan, Nayarit, Tamaulipas) bajo el Consejo Regulador del Tequila

38% – 40% vol. alc. (72 - 96 proof)

(Aguardiente) Destilado de Agave Azul (Norma tec. 51% min)
(agave azul tequilana weber)

## Proceso

- Jima
- Hidrólisis
- Extracción jugos, desgarramiento
- Fermentación (72 horas)
- Destilacion (2 o 3 destilación en alambiques; primero 25%-35%; segundo 38%-55% )
- Reposo, añejamiento
- Dilución, filtrado, embotellamiento

## Tipos

- Blanco o Plateado : 1 Mes
- Reposado : min 2 Meses - 1 Año
- Añejo : min 1 Año
- Extra Añejo : 3 a 4 Años
- Mezcal: Diferentes agaves, una sola destilación, sabor agresivo, tiene un gusano maguey (rojos y blancos)

# Gin (Reino Unido)

40% - 43% vol. alc. (80 y 86 proof)

(Aguardiente) Destilado de Cereales almidonados (cebada malteada, maiz, centeno) rectificado con Enebro y diferentes botanicos

Ginebra (Holanda) mismo proceso, pero con menos botanicos

## Proceso

- Moliente, cocción
- Fermentación
- Destilación (Coffey - aguardiente 96 GL)
- Rectificación, Saborización (agregado elementos botanicos)
- Dilución (+ agua 40 y 47 GL)
- Filtrado
